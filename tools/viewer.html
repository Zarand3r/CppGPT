Logit lens — where the prediction forms

The residual stream at each layer, read through the final layernorm and the tied unembedding: what would the model predict if it stopped here?

The lens borrows the final layernorm for every layer, but each layer's residual has its own scale, so early layers are distorted. Belrose et al.'s tuned lens fixes this with a learned per-layer probe; this is the plain lens, so read early layers as indicative, not quantitative.

Which layer moved the prediction

KL divergence in nats, at the final position. step = how far this layer moved the prediction from the previous one; to output = how far it still is from the model's answer. A near-zero step is a layer that is near-identity for this input. This is the quantity the residual norm below only approximates.

Residual stream norm

‖residual‖ per layer at the selected position. Flat segments are layers that barely move the representation.

What pushed this prediction

Direct logit attribution. Every component writes into the residual stream, and the final layernorm is affine once its scale is fixed — so each component's push on the predicted token's logit is exact, and the parts sum to the whole. Blue raised it, orange lowered it.

This is the direct effect only — what a component wrote into the output direction. A head can matter enormously while attributing near zero, by changing what later layers do. The ablation map beside this measures that total effect; where the two disagree is the interesting part.

Ablate a component

Each component silenced in turn, the model re-run, and the new output compared with the baseline (KL divergence, nats). Darker is more load-bearing. MLP and attn are the whole block rather than a single head. Hover for the effect on the predicted token's probability.

Exhaustive: every head, every MLP, every attention block, each its own forward pass. That is routine at this scale and infeasible at production scale — which is why the literature reaches for gradient approximations that this model does not need.

The sequence becoming tokens

Each column is a position, each row a layer: the model's top-1 prediction if it stopped there. Read a column downward to watch one position resolve; read a row across to see what the whole sequence looks like at that depth. Cell shading is confidence.

Positional encoding — how much each position learned

GPT-2 learns its positional embeddings. wpe is a trained parameter initialised to N(0, 0.02) and updated by gradient descent like any weight — not a fixed sinusoid, so there is something here that training actually shaped.

Position similarity

Cosine similarity between position vectors — blue positive, orange negative. A model that learned locality shows a bright band along the diagonal, because nearby positions end up encoded alike. One that has not still looks like its initialisation, where distinct random rows are near-orthogonal and everything off the diagonal is dark.

Attention on the context

Pick a query position and a head: the text below is shaded by how much that query attended to each earlier character. This is the same data as the matrices, read the way you actually think about it.

Head summary

Entropy — low means the head focuses on few positions. Distance — mean q−k weighted by attention; ≈1 is a previous-token head. →first — mass on position 0, the "attention sink".

Attention matrices

Each cell is one head: rows are query positions, columns are keys. Lower-triangular by construction — a token can only attend to itself and its past.

Attention is routing, not explanation. A bright cell means information moved, not that it mattered. Jain & Wallace (2019) and Wiegreffe & Pinter (2019) both show attention weights can be altered substantially without changing the prediction. Reading a story off these maps is the classic mistake; use them to form hypotheses that a causal method then has to confirm — which is exactly what the ablation map above is for.
